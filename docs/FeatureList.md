## 项目概览
### 功能概述
本软件面向嗅觉心理学及生理学等实验场景，定位为“实验范式—硬件”的中间控制层与数据管理枢纽。其核心目标是在保持实验范式灵活性的前提下，实现对嗅觉刺激装置的可重复、可追溯与可验证的执行控制。

本系统在架构上将实验范式编排与刺激执行控制相分离。本软件在启动后完成嗅觉刺激装置的初始化并进入待触发状态；SuperLab通过数字I/O设备NI-USB-6501的数字输入（或者外部触发源通过多功能数据采集设备NI-USB-6001的模拟输入）向本软件发送试次推进信号；当接收到触发信号时，从本地参数文本按行解析本次试次的控制量，包括持续时间、载气流速、排空流速及气味流速等；通过RS232将目标流速下发至嗅觉刺激装置内部的质量流量控制器，并经NI-USB-6001的数字输出接口控制相应电磁阀的通断，实现气味刺激的时序调度。在设定持续时间终止时，软件关闭电磁阀并将流量计复位至基线流速，并自动记录整个执行流程的指令序列与设备状态用于追溯。该架构确保触发端、软件调度端与硬件执行端相互独立，从而便于在不同实验范式间复用同一套气味刺激硬件。

本软件的功能架构以“页面即子系统”的方式组织：文件、校准、预测试、协议模式、清洗与选项六个页面分别承担实验文件与参数管理功能、呼吸信号校准功能、预测试功能、协议化自动执行功能、气路清洗功能以及系统参数配置功能。

## 文件页面
### 功能说明
文件页面是系统运行的起始配置界面，主要用于实验被试信息的输入、数据保存路径的设定以及实验参数文件的加载。该页面不仅负责实验数据的命名与存储，同时承担实验执行参数的载入功能，是整个系统数据结构的核心入口。
- **被试信息管理**：支持录入被试基本信息，自动化文件命名保证数据文件唯一性与规范性。
- **数据存储路径配置**：存放嗅觉刺激装置行为参数、呼吸数据。
- **执行参数加载**：加载实验执行参数文件。

### 界面设计
1. **常驻按键（后续页面不再说明）**
- 连接刺激器：按下后，软件与嗅觉刺激装置建立通信，允许参数下发与实时控制。本按钮应先于校准、预实验、协议执行等功能使用。
- 重置刺激器状态：在运行中设备失去响应或参数更改后，可使用该按钮重新初始化硬件，而无需退出软件。
- 停止使用刺激器（不退出软件）：此按钮仅停止使用硬件控制，使界面恢复到非运行状态，便于切换实验或检查设置。
- 帮助：打开软件说明书。
2. **文件命名**
- **受试者**：用于输入实验被试的名称或标识符。
- **性别**：下拉菜单，提供“男”与“女”等选项。
- **当前文件名**：系统根据输入的主体信息、性别及时间戳自动生成实验文件名称。
- **自定义命名框**：默认写olfacto。
- **自动生成文件名开关**：启用后，文件名为自动生成的“当前文件名”，否则为“自定义命名”。
3. **数据保存目录**
- **保存路径**：定义实验数据与执行参数的存储目录（默认路径C:\Data）。在此目录中，系统将存储两类文件：
- **实验气流参数文件**（.txt文件）。内容为多行气流控制参数，每行包含五个字段：持续时间（ml）、20个通道状态（1表示启用）、空气流速（ml/min）、排空流速（ml/min）、气味流速（ml/min）等。系统在实验执行时，依据预设协议读取对应行参数，实现自动化气流控制。
- **实验数据文件**。顺序记录实验执行的各试次具体信息，包括时间戳、控制参数、呼吸数据等必要信息。

## 校准页面
### 功能说明
校准页面用于实验前的呼吸信号标定。研究对象通过呼吸气路进行自然呼吸，系统采集气压传感器输出的压力信号，并依据设置的校准时长与吸/呼气阈值自动识别吸气与呼气节律，从而保证后续实验触发条件与个体生理信号相匹配，实现基于呼吸启停的气味释放控制。
- **呼吸信号校准**：通过设定校准时长与阈值，系统能够区分个体的吸气与呼气模式。
- **动态信号监控**：实时显示呼吸波形，系统会对输入的气压信号进行自动幅度缩放，采集窗口内的最大值与最小值作为缩放参考，系统动态计算偏移量与增益，使波形始终占据绘图区的主要可视区域。
- **启动与中断**：支持启动与中断校准操作。

### 界面设计
1. **参数输入**
- **校准时长（sec）**：设定校准过程的持续时间（单位：秒）。
- **呼气检测阈值（红色，正向部分）**：设定呼气信号的检测阈值，用于识别呼气过程（正向部分）。
- **吸气检测阈值（黄色，负向部分）**：设定吸气信号的检测阈值，用于识别吸气过程（负向部分）。

2. **实时监测**
- 左侧黑色图形区域实时呈现三条独立曲线，用于可视化校准过程与触发逻辑：
	- **白色曲线**：呼吸压力信号，用于观察实验对象的吸气-呼气周期；
	- **红色水平线**：呼气检测阈值（手动调整）。一般而言，当白线呼气压力超过该阈值时，系统判定“达到触发条件”并下发刺激指令；
	- **黄色水平线**：吸气检测阈值（手动调整）。也作为Trig IN事件指示，标记实际嗅觉刺激到达输出端的时间点。
- **右侧状态条**：显示当前校准状态（如“等待中”、“剩余校准时间”），以及展示校准时长的时间进度。
- 数值参数显示：
	- **最大值与最小值**：实时统计当前呼吸信号的幅度范围。
	- **偏移量**：动态调整信号基线，使波形处于合适可视范围。
	- **增益**：信号幅度动态放大或压缩，使完整波形占据显示窗口。
3. **操作控制**
- **启动校准**（绿色按钮）：开始执行校准过程。
- **中断校准**（黄色按钮）：手动终止校准过程。

## 预测试页面
### 功能说明
预测试页面用于在正式实验前，对嗅觉刺激系统的硬件配置、气流参数及气味通道进行验证。通过该页面，研究人员能够灵活控制气味呈现参数（如流速、持续时间），并检查实验装置的工作状态，确保实验条件符合预期，从而避免在正式实验中出现偏差。
- **多通道控制**：最多支持20个气味源的独立开关。
- **气流参数调节**：可灵活设置空气流速（流量控制器B）、排空流速(流量控制器C)及补偿流速（流量控制器A）（毫升每分钟）及时长（毫秒）。
- **信号状态监控**：实时显示波形与系统指示灯，支持切换手动触发和呼吸检测触发两种模式。
- **启动与中断**：支持启动与中断预测试。

### 界面设计
1. 气味通道选择**
提供**1–20**个独立通道开关按钮（编号1至20），用户可手动启用或关闭特定气味源。通道开关通过按钮颜色及状态指示，可同时选择数道。
2. **参数设定**
- **空气流速（B）（ml/min）**：恒定载气，始终保持B不变，用于保证传输通道与嗅觉端口的稳定基流。
- **排空流速（C）（ml/min）**：在无刺激阶段用于模拟被试吸入的流量，值为输入数值C；有刺激阶段置零。
- **补偿/气味流速（A）（ml/min）**：在无刺激阶段通过空气补加的流速，以维持出口总送风恒定，补偿流速Acomp=输入数值A+排空流速C；在有刺激阶段通过气味通道释放气味的流速，气味流速Aodor=输入数值A。实现有刺激与无刺激两种工况下出口供气流速一致。
- **气味持续时间（msec）**：设定气味刺激的持续时间（单位：毫秒）。
3. **实时监测**
- 左侧黑色图形区域：用于显示气流信号或呼吸信号波形。
- 右侧状态区，包括以下指示灯：
	- **手动触发**：模式指示灯，可点击，点亮表示启用。（当前默认需要启用）
	- **吸气检测**：状态指示灯，检测到吸气时变亮。（用于呼吸启停）
	- **呼气检测**：状态指示灯，检测到被试呼气时变亮（有呼吸进入时）
4. **操作控制**
- **启动测试**（绿色按钮）：开始执行预测试流程。
- **中断测试**（黄色按钮）：手动终止预测试。

## 协议模式界面
### 功能说明
协议模式页面是系统进行正式实验的核心界面，用于按照预设实验协议自动执行气味刺激。在实验开始前，需先在该界面运行控制软件，以确保与下游硬件完成初始化与待触发状态的建立。
- **外部触发模式（勾选Manual）**：当启用与上位范式系统联动时，SuperLab通过数字I/O设备NI-USB-6501发送8位二进制触发信号至本软件。例如10000001，表示参数文件的第128行，其中最高位为触发标志（Trig.In）。当检测到触发位有效时，系统解析该行协议参数并立即执行相应试次。若启用呼吸触发，则在收到外部触发后进入呼吸监测，当呼吸信号超过阈值时触发该行执行，实现“外部试次推进+个体呼吸节律控制”的双重约束。
- **自主顺序执行模式（未勾选 Manual）**：在无外部范式系统参与时，控制软件将按照参数文件的行序自动推进试次。若启用呼吸触发，则每行在达到呼气阈值时执行一次；未启用呼吸触发则按设定的行间隔时间顺序执行。
- **实验信息管理**：实时显示试次编号。
- **启动与中断**：支持启动与中断实验。

### 界面设计
1. **实验信息**
- **试次编号**：显示当前实验的试次序号。

2. **实时监测**
- 左侧黑色图形区域：用于显示气流信号或呼吸信号波形。
- 右侧状态区，包括以下指示灯：
	- **手动触发**：模式指示灯，可点击，点亮表示启用。（当前默认需要启用）
	- **同步触发**：状态指示灯，检测到信号同步时变亮。（可能需要加按键）
	- **呼气检测**：状态指示灯，检测到被试呼气时变亮。（红线，呼气阈值，放刺激）
3. 操作控制**
- **启动实验**（绿色按钮）：启动实验协议，按预设条件执行刺激。
- **中断实验**（黄色按钮）：手动终止实验过程。

## 清洗页面
### 功能说明
清洗页面用于在实验前后或实验间隔中，对嗅觉刺激装置的气路进行冲刷，避免残留气味对后续试次造成干扰。用户可设定清洗总时长及单阀门开闭驻留时长，系统按设定对各气味通道电磁阀进行轮换开通。在清洗过程中，将载气流速与排空流速置为指定的空气清洗流量，并将气味流速置零；同时按轮换策略控制电磁阀开闭以完成通道式冲刷。
- **气路系统清洗**：通过设定清洗周期和电磁阀开闭时长。
- **启动与中断**：支持启动与中断清洗。

### 界面设计
1. **清洗参数设置**
- **清洗总周期时长（min）**：设定~~完~~整个清洗流程的持续时间（单位：分钟）。
- **电磁阀开启时长（sec）**：定义电磁阀单次打开的持续时间（单位：秒）。
- **正在清洗的电磁阀编号**：实时显示当前正在执行清洗操作的电磁阀编号。
2. **操作控制**
- **启动清洗**（绿色按钮）：开始执行清洗操作。
- **中断清洗**（黄色按钮）：立即终止清洗过程。

## 选项页面
### 功能说明
选项页面用于对系统运行进行高级参数设置，包括数据采集参数、图形显示设置、触发与同步配置，以及用户界面的个性化定制。
- **数据采集与硬件配置**：设置采样率与流速参数，支持多设备选择与串口通信端口设置。
- **实验流程参数设置**：研究人员可灵活设定气味呈现的前后时长、刺激间隔与触发延迟等。
- **界面个性化调整**：配置图像大小、字体大小与颜色等。

### 界面设计
1. **数据采集与硬件配置**
- **采集频率（Hz）**：设定系统数据采样率。
- **图表刻度（最大值）**：设定图形显示的纵轴范围上限。
- **持续吸入流速（ml/min）**：设定系统维持的基础吸入流量。
- **设备配置**：选择使用的设备，并指定通信端口（Port COM）与版本号。（当前Dev1（12道）/Dev2为6001（Dev2总阀），Dev3为6501，COM6为RS232）
- Version：四位二进制指定通道数。
2. **实验流程参数设置**
- **编辑.ini文件**：支持直接编辑配置文件，便于快速批量修改参数。
- 结果文件时间戳：启用后在实验结果文件中记录精确时间戳。
- **预测试：**
	- **气味呈现前等待时长（msec）**
	- **气味呈现后休息时长（msec）**
- **协议模式与PsychoSniff测试：**
	- **“空”扫描次数**（-1代表人为指导被试者）
	- 响应间隔时长（msec）与吸气触发延迟（msec）
	- 休息时长（msec）
	- 休息文本
- **硬件模拟 (新增)**：
    - **启用模拟模式**：允许在无物理硬件连接的情况下运行软件。
    - **模拟参数**：配置模拟呼吸波形的频率和幅值。
3. **显示与界面配置区**
- **“受试者”窗口屏幕偏移量（pixel）**
- **图像大小（pixel）**：设定实验图像的宽度与高度。
- **字体、标签、光标大小**
- **显示/隐藏“受试者”窗口**
4. **界面反馈与配色设置****
- **响应结果颜色设置**：
	- “正确”反馈：绿色。
	- “错误”反馈：红色。
- **界面元素配色**：
	- 背景、文本、刻度、标签。
