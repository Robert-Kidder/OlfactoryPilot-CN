# OlfactoryPilot-CN 功能清单

## 已完成或基本完成

- PySide6 桌面应用骨架。
- MVC + Worker + HAL 基础结构。
- Mock HAL 硬件模拟模式。
- 启动自检和连接状态展示。
- 全局连接、重置、停止、帮助工具栏。
- 气流安全联锁。
- 安全退出和阀门复位。
- 呼吸波形实时显示。
- 呼气/吸气阈值调节与状态反馈。
- 10/20 通道阀门矩阵预实验界面。
- Alicat A/B/C 流量控制基础能力。
- 主阀与补偿逻辑基础能力。
- 本地 ruff、pytest、PyInstaller 和 GitHub Actions CI。

## 下一阶段优先功能

- 解析旧系统兼容的 `.txt` 和 `.csv` 实验协议文件。
- 显示协议摘要、trial 列表和解析错误行号。
- 建立协议执行状态机。
- 支持手动触发实验。
- 支持 TTL 外部触发实验。
- 实现呼吸门控刺激。
- 记录阀门动作时序和软件抖动。
- 自动生成 `.raw` 信号文件和 `.log` 事件日志。

## 后续功能

- 自动清洗流程。
- COM 端口和 NI 设备 ID 的完整界面配置。
- 配置校验和持久化。
- 中文帮助文档入口。
- 更完整的真实硬件验证记录。

## 长期不做或暂不做

- 云端同步。
- 多用户协作。
- Web 或移动端版本。
- 实验数据统计分析平台。
- 多语言界面。
