# 历史资料归档

本目录保存不再维护但仍需审计的资料。归档文件保留其形成时的状态与措辞，不作为当前产品、硬件或实施状态的权威来源。

- `sprint-artifacts/`：已完成 Story、execution spec、代码评审、复盘、旧变更提案、规划状态和历史状态快照。
- `FeatureList-legacy.md`：早期功能清单快照。

当前规则以父目录中的 `project-context.md`、`prd.md`、`architecture.md`、`ux-design.md` 和 `project-structure.md` 为准；当前进度只看 `../sprint-artifacts/sprint-status.yaml`；安全、HIL、极性和发布证据仍保存在 `../sprint-artifacts/evidence/`。
