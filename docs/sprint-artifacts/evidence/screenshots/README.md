# Simulation UI-reference fixtures

本目录保存经人工接受后迁移的 simulation UI 参考截图，供界面回归与文档审阅使用。`manifest.json` 固定来源 revision 与 SHA-256；文件字节在迁移时保持不变。更新截图必须经过新的显式审阅，不能由常规测试或 clean-clone 自动改写。

这些图片仅来自 Mock HAL / simulation，不是物理设备、HIL、现场确认或 `PHYSICAL_VERIFIED` 证据，也不得据此宣称真实硬件可用。
